Если Windows показывает предупреждение

У новых программ без платной цифровой подписи Windows иногда показывает синее окно «Система Windows защитила ваш компьютер». Это не вирус — так Windows реагирует на любую малоизвестную программу.

  1. В синем окне нажмите «Подробнее».
  2. Появится кнопка «Выполнить в любом случае» — нажмите её.
  3. Если браузер пишет «Файл скачивают редко», нажмите «…» → «Сохранить» → «Всё равно сохранить».
Стоимость для школы — по запросу в WhatsApp. Первые школы-участники пилота получают ключ на льготных условиях.

Частые вопросы

Как сделать, чтобы школьные звонки звенели автоматически?

Установите Qonyrau на компьютер, к которому подключены колонки или микшер школы, впишите время уроков — программа сама даёт звонки на урок и с урока каждый день по расписанию.

Нужен ли интернет?

Нет. Qonyrau работает без интернета. Интернет нужен только чтобы сверить точное время, если эта функция включена.

Можно ли включать гимн РК только по понедельникам?

Да. В разделе «Музыка по времени» выберите время, дни недели и файл гимна — он будет играть только в выбранные дни.

Есть ли программа на казахском языке?

Да. Интерфейс переключается между казахским, русским и английским одной кнопкой.

Что будет, если компьютер выключат?

Пока компьютер выключен, звонков не будет. Программа запускается вместе с Windows и не даёт компьютеру уснуть, а после включения сразу продолжает работу по расписанию.

Сколько стоит?

Первые 30 дней — бесплатно со всеми функциями. Стоимость ключа для школы — по запросу в WhatsApp.
